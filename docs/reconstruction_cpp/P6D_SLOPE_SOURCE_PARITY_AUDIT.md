# P6D1 SLOPE — original CALMET source-scoped reconstruction

Date: 2026-10-11. Scope: **isolated source-faithful `SLOPE` subroutine only**. Not a complete P6D solver or P6 scientific acceptance.

## Frozen source and controls

- Original `engine/vendor/src/CALMET_v6.5.0_L150223/calmet.for`, Git blob `437f43bb7f0e51a1919e56664663e1a046986ed0`, `SLOPE` lines 30372–30604.
- Calls `SLOPE(USLOPE, VSLOPE, HTOPO, ISURFT, TINF, TEMP2D, HMAX)`. Reads common-block `QH` sensible heat flux, `ILANDU` and inclusive water category bounds, `ZFACE`, `HMIN`, `DISTHMAX/MIN`, `DX/DY`.
- C++ input contracts require all physical fields and masks explicitly; no guessed heat flux, no substituted precipitation and no default "all land".
- Original 32-bit constants: `RHOCP=1229.9`, `CDK=0.08`, `RPD=0.017453`, `DPR=57.296`. Mahrt downslope/upslope flow; `QH<0` downslope, `QH>=0` upslope; no flow over water, weak gradients or above flow thickness. Fortran REAL*4 replicated where meaningful.
- `ISURFT>0 || ISURFT==-2` takes representative `TINF`; otherwise `TEMP2D(i,j)`.

## Implementation and tests

- `include/cteas/p6/slope_flow.hpp`: isolated C++20 physical kernel.
- `src/slope_flow_main.cpp`: fixed 50×50×9 numerical-comparison CLI.
- `tests/p6_slope_flow_tests.cpp`: stable/convective flux, water suppression, height thickness, flat terrain and missing-input fail-closed.
- `reference/compare_original_slope.py`: extracts literal untouched Fortran original `SLOPE` block; stubbed external `XMIT/WNDLPT` only (initialization and diagnostics, no numerical physics alteration). Builds with frozen vendor includes and compares C++ outputs against real Fortran evaluation, exact row/layer order, declared `2e-4 m/s` component tolerance, valid finite fields, water masks.
- `.github/workflows/p6d-calmet-slope-parity.yml`: independent original source build + full CTest + audited comparison, JSON artifact.

Four independent synthetic forcing/terrain cases: flat, nighttime ridge, daytime ridge, and mixed sensible heat with water cells. These are **not 2022 real hourly meteorological forcing**, and precomputed manufactured expected arrays are not treated as original reference truth.
